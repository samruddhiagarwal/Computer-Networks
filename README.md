## 📋 Course Overview

This repository contains all the laboratory exercises and practical assignments completed as part of the **Computer Networks Laboratory** course at MIT-WPU. The course is designed to give hands-on experience with core networking concepts ranging from data link layer protocols to application layer services.

---

## 🎯 Course Objectives

### 1. Knowledge
- Understand the **fundamentals of networking and data communications**
- Understand basics of **physical and data link layers**

### 2. Skill
- Learn **network layer protocols**
- Explore **services offered by the transport layer**

### 3. Attitude
- Understand **protocols of the application layer**

---

## 🏁 Course Outcomes

Upon completion of this course, students are able to:

1. Identify and characterize **features of transmission techniques**
2. Recall and demonstrate working of **flow control & error control protocols**
3. Select routing protocol to develop **fully-functional simulations** to demonstrate its working
4. Define **connection-oriented & connectionless transport layer protocols** and build working applications based on them
5. Choose an **application layer protocol** and make use of it in a suitable environment

---

## 🧪 Laboratory Exercises / Practicals

The following practicals are carried out as per the course curriculum. Each program is evaluated as part of **continuous assessment** and submitted as a journal.

| # | Topic | Language(s) |
|---|-------|-------------|
| 1 | Design a Simple Network using different **network topologies** (Star, Mesh, Bus, Extended Star, etc.) | Packet Tracer / GNS3 |
| 2 | Implement **Error Control Protocol** — Error detection and correction (Hamming Code) | C / C++ / Python / Java |
| 3 | Write a program to demonstrate **Subnetting** and find subnet masks | C / C++ / Python / Java |
| 4 | Write a program to simulate **Distance Vector Routing Algorithm** | C / C++ / Python / Java |
| 5 | Write a program for **TCP Socket Programming** | C / C++ / Python / Java |
| 6 | Write a program for **UDP Socket Programming** | C / C++ / Python / Java |
| 7 | **DHCP, DNS, Web Server and Email** configuration in Cisco Packet Tracer | Cisco Packet Tracer |
